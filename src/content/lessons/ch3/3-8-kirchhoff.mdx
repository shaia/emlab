<Hook title="מי טוען את מי?">

כשמתניעים רכב עם מצבר חלש, מחברים אליו בכבלים מצבר תקין של רכב אחר. ובזמן נסיעה, הגנרטור של הרכב, שנכיר בפרק 5, דוחף זרם **לתוך** המצבר וטוען אותו. אז זרם יכול לזרום לתוך ההדק החיובי של סוללה? ואיך יודעים, במעגל עם שתי סוללות, לאן הזרם זורם בכל ענף?

במעגלים של שיעור 3.5 הסתדרנו עם טור ומקביל. כשיש שתי סוללות בענפים שונים, המעגל כבר לא מתפרק לטור ולמקביל. בשיעור הזה נלמד שני חוקים כלליים, שניסח לראשונה גוסטב קירכהוף בשנת 1845, ומספיקים כדי לפתור כל מעגל. ושניהם כבר מוכרים לנו.

</Hook>

<Step fig="fig-3-8a" set={{ preset: 'kirchhoff', loop: 'left', values: { eps2: { emf: 3 } } }}>

במעגל של איור 3.8א יש שני <Term id="junction">צמתים</Term>: אחד למעלה ואחד למטה, בעמודה האמצעית. ביניהם שלושה <Term id="branch">ענפים</Term>, ובכל ענף זרם אחד, שמד הזרם שלו מראה: $2\,\text{A}$ בענף השמאלי, $1\,\text{A}$ באמצעי, $1\,\text{A}$ בימני.

הסתכלו על הצומת העליון. מהענף השמאלי נכנסים $2\,\text{A}$. יוצאים ממנו $1\,\text{A}$ למטה דרך $R_3$, ו-$1\,\text{A}$ ימינה דרך $R_2$, **אל** ההדק החיובי של $\varepsilon_2$. נכנסים $2\,\text{A}$, ויוצאים $1 + 1 = 2\,\text{A}$.

**החיזוי שלכם מקבל כאן תשובה:** הזרם נכנס להדק החיובי של הסוללה הקטנה. היא מקבלת אנרגיה, כמו מצבר שנטען.

</Step>

<Step fig="fig-3-8a" set={{ preset: 'kirchhoff', loop: 'left', values: { eps2: { emf: 3 } } }} id="left">

עכשיו גרף הגובה. הוא מראה את ה<Term id="loop">לולאה</Term> השמאלית: מסלול סגור שיוצא מהנקודה A, ההדק השלילי של $\varepsilon_1$, ועובר דרך $\varepsilon_1$, $R_1$ ו-$R_3$ בחזרה ל-A.
בסוללה הפוטנציאל עולה ב-$12\,\text{V}$. ב-$R_1$ הוא יורד ב-$IR = 2\cdot3 = 6\,\text{V}$, וב-$R_3$ בעוד $1\cdot6 = 6\,\text{V}$. בחזרה ל-A: $12 - 6 - 6 = 0$.

</Step>

<Step fig="fig-3-8a" set={{ preset: 'kirchhoff', loop: 'right', values: { eps2: { emf: 3 } } }} id="right">

עברו ללולאה הימנית: מההדק השלילי של $\varepsilon_2$, דרך $\varepsilon_2$, שמאלה דרך $R_2$, למטה דרך $R_3$, וחזרה. ב-$\varepsilon_2$ אנחנו הולכים מ-− ל-+, ולכן הפוטנציאל עולה ב-$3\,\text{V}$, אף שהסוללה נטענת: בסוללה הסימן תלוי רק בכיוון ההליכה, לא בכיוון הזרם. ב-$R_2$ אנחנו הולכים **נגד** כיוון הזרם, ולכן הפוטנציאל **עולה** ב-$1\cdot3 = 3\,\text{V}$. ב-$R_3$, עם הזרם, הוא יורד ב-$6\,\text{V}$. ושוב: $3 + 3 - 6 = 0$. כל לולאה, גם החיצונית, חוזרת לגובה שבו התחילה.

</Step>

<Step fig="fig-3-8a" set={{ preset: 'kirchhoff', loop: 'left', values: { eps2: { emf: 3 } } }} id="flip">

הגדילו את הכא"מ של $\varepsilon_2$. הזרם ב-$R_2$ קטן, וכשהכא"מ עובר את $8\,\text{V}$ הוא מתהפך: עכשיו הזרם יוצא מההדק החיובי של $\varepsilon_2$, ושתי הסוללות מספקות אנרגיה, אף ש-$\varepsilon_2$ עדיין קטנה מ-$12\,\text{V}$. למה דווקא $8\,\text{V}$? כשאין זרם ב-$R_2$, הזרם של $\varepsilon_1$ עובר כולו ב-$R_1$ וב-$R_3$: $12/(3+6) = \tfrac43\,\text{A}$, והצומת העליון ב-$6\cdot\tfrac43 = 8\,\text{V}$. מי שקובע מי טוען את מי הוא הפוטנציאל של הצומת, לא רק הכא"מ של כל סוללה.

</Step>

<Explain title="חוק הצמתים: שימור המטען" id="junction-rule">

<Term id="junction-rule">חוק הצמתים</Term>, החוק הראשון של קירכהוף: בכל צומת, סכום הזרמים שנכנסים שווה לסכום הזרמים שיוצאים.

<Formula tex="\sum I_{\text{in}} = \sum I_{\text{out}}" label="חוק הצמתים" />

זה שימור המטען (שיעור 1.1): מטען לא נוצר בצומת ולא נעלם בו, וכשהזרמים לא משתנים הוא גם לא מצטבר בו. אותו רעיון ראינו בשיעור 3.2, כשהזרם לפני הנורה ואחריה היה שווה. החוק לא אומר **איך** הזרם מתחלק: את זה קובעים הענפים עצמם.

</Explain>

<Explain title="חוק הלולאות: פוטנציאל אחד בכל נקודה" id="loop-rule">

<Term id="loop-rule">חוק הלולאות</Term>, החוק השני של קירכהוף: סכום השינויים בפוטנציאל לאורך כל לולאה סגורה הוא אפס.

<Formula tex="\sum \Delta V = 0" label="חוק הלולאות (סכום השינויים בפוטנציאל בלולאה סגורה)" />

זה מה שראינו כבר בשיעור 3.1: לכל נקודה פוטנציאל אחד, כי השדה האלקטרוסטטי משמר (שיעור 2.1), ולכן סיבוב שלם חוזר לאותו גובה. כדי לכתוב את המשוואה, בוחרים כיוון הליכה סביב הלולאה, ולכל רכיב רושמים את השינוי עם סימן:
- **סוללה:** מ-− ל-+ הפוטנציאל עולה, $\Delta V = +\varepsilon$. מ-+ ל-− הוא יורד, $\Delta V = -\varepsilon$. הסימן תלוי רק בכיוון ההליכה, לא בכיוון הזרם.
- **נגד:** בכיוון הזרם הפוטנציאל יורד, $\Delta V = -IR$. נגד כיוון הזרם הוא עולה, $\Delta V = +IR$. כשהזרמים עוד לא ידועים, "כיוון הזרם" הוא הכיוון **שסימנו** לו. אם בסוף הזרם יוצא שלילי, הסימן מתקן גם את זה.

</Explain>

<Explain title="פותרים מעגל עם שתי סוללות" id="solve">

אפשר לפתור את המעגל של איור 3.8א בלי לראות את מדי הזרם, בארבעה שלבים:

1. **מסמנים זרם בכל ענף, עם כיוון לבחירתנו.** נבחר $I_1$ יוצא מההדק החיובי של $\varepsilon_1$ אל הצומת העליון, $I_2$ יוצא מההדק החיובי של $\varepsilon_2$ אל אותו צומת, ו-$I_3$ יורד דרך $R_3$.
2. **חוק הצמתים** בצומת העליון: $I_1 + I_2 = I_3$. (בצומת התחתון יוצאת אותה משוואה, ולכן מספיק צומת אחד. ושתי לולאות מספיקות: משוואת הלולאה החיצונית היא ההפרש בין שתי האחרות, ולא מוסיפה מידע.)
3. **חוק הלולאות** בשתי לולאות, עם כיוון הזרמים שבחרנו. בלולאה השמאלית $12 - 3I_1 - 6I_3 = 0$, ובלולאה הימנית $3 - 3I_2 - 6I_3 = 0$.

4. **פותרים.** מהלולאות: $I_1 = 4 - 2I_3$ ו-$I_2 = 1 - 2I_3$. מציבים בחוק הצמתים: $5 - 4I_3 = I_3$, ולכן $I_3 = 1\,\text{A}$, $I_1 = 2\,\text{A}$, ו-$I_2 = -1\,\text{A}$.

שימו לב: במשוואה הימנית כתבנו $-3I_2$, כי סימנו את $I_2$ יוצא מ-$\varepsilon_2$, כלומר בכיוון ההליכה. בצעד "הלולאה הימנית" ראינו על אותו נגד עלייה של $3\,\text{V}$. אין סתירה: $-3I_2 = -3\cdot(-1) = +3\,\text{V}$.

**מה אומר הסימן השלילי?** את הכיוון של $I_2$ בחרנו בלי לדעת. התוצאה $I_2 = -1\,\text{A}$ אומרת שהזרם האמיתי הוא $1\,\text{A}$ בכיוון ההפוך: מהצומת **אל** ההדק החיובי של $\varepsilon_2$, בדיוק מה שהאיור מראה. אין צורך לפתור מחדש.

**מאזן אנרגיה.** $\varepsilon_1$ מספקת $12\cdot2 = 24\,\text{W}$. הנגדים מקבלים

$$
I_1^2R_1 + I_3^2R_3 + I_2^2R_2 = 2^2\cdot3 + 1^2\cdot6 + 1^2\cdot3 = 21\ \text{W}
$$

ו-$\varepsilon_2$ מקבלת $3\cdot1 = 3\,\text{W}$. בסוללה נטענת (מצבר) הם נאגרים כאנרגיה כימית; בסוללה רגילה, שאי אפשר לטעון, הם הופכים לחום. $21 + 3 = 24$.

<Note>
בבגרות המעגלים כוללים לכל היותר שני צמתים, כמו כאן: משוואת צומת אחת ושתי משוואות לולאה, לשלושה זרמים.
</Note>

</Explain>

</Spread>

<Example title="מעגל עם שתי סוללות">

במעגל באותו מבנה כמו באיור 3.8א, בענף השמאלי יש סוללה אידאלית $\varepsilon_1 = 18\,\text{V}$ ונגד $R_1 = 2\,\Omega$. בענף הימני סוללה אידאלית $\varepsilon_2 = 9\,\text{V}$ ונגד $R_2 = 3\,\Omega$, ובענף האמצעי נגד $R_3 = 6\,\Omega$. ההדקים החיוביים של שתי הסוללות פונים אל הצומת העליון.
(א) מצאו את הזרם בכל ענף. (ב) האם $\varepsilon_2$ מספקת אנרגיה או מקבלת?

<Solution>

**(א)** **סימון:** $I_1$ ו-$I_2$ יוצאים מההדקים החיוביים אל הצומת העליון, $I_3$ יורד דרך $R_3$.

**חוק הצמתים:** $I_1 + I_2 = I_3$.

**חוק הלולאות**, בכל לולאה מההדק השלילי של הסוללה שבה, עם הזרם שסימנו בה ודרך $R_3$:

$$
18 - 2I_1 - 6I_3 = 0 \qquad\qquad 9 - 3I_2 - 6I_3 = 0
$$

**פיתוח:** $I_1 = 9 - 3I_3$ ו-$I_2 = 3 - 2I_3$. בחוק הצמתים: $12 - 5I_3 = I_3$.

**תוצאה:** $I_3 = 2\,\text{A}$, $I_1 = 3\,\text{A}$, $I_2 = -1\,\text{A}$.

**(ב)** $I_2$ שלילי: הזרם נכנס להדק החיובי של $\varepsilon_2$, ולכן היא **מקבלת** אנרגיה, $9\,\text{V}\cdot1\,\text{A} = 9\,\text{W}$.

<Note>
בדיקה בלולאה החיצונית, עם הזרמים האמיתיים: דרך $\varepsilon_1$ למעלה הפוטנציאל עולה ב-$18\,\text{V}$; דרך $R_1$ עם הזרם הוא יורד ב-$2\cdot3 = 6\,\text{V}$; דרך $R_2$ עם הזרם האמיתי, אל $\varepsilon_2$, יורד ב-$3\cdot1 = 3\,\text{V}$; ודרך $\varepsilon_2$ מ-+ ל-− יורד ב-$9\,\text{V}$. הסכום: $18 - 6 - 3 - 9 = 0$.
</Note>

</Solution>

</Example>

<Watch id="v-3-8-circuit-laws" title="חוקי הזרם והמתח (רשות)">

מבוא מונפש באנגלית, עם כתוביות בעברית, למעגלים חשמליים ולשני החוקים של קירכהוף. השוו את ההסבר לגרף הגובה שבאיור 3.8א.

</Watch>

<Summary title="מה למדנו">

- **חוק הצמתים:** בכל צומת $\sum I_{\text{in}} = \sum I_{\text{out}}$. זה שימור המטען.
- **חוק הלולאות:** בכל לולאה סגורה $\sum\Delta V = 0$, כי לכל נקודה פוטנציאל אחד. בסוללה מ-− ל-+: $\Delta V = +\varepsilon$; בנגד בכיוון הזרם: $\Delta V = -IR$.
- **פתרון מעגל:** מסמנים זרמים בכיוונים לבחירתנו, כותבים משוואת צומת ומשוואות לולאה, ופותרים.
- **זרם שלילי** אינו טעות: הוא זורם בכיוון ההפוך לזה שסימנו.
- סוללה שהזרם נכנס להדק החיובי שלה **מקבלת** אנרגיה, ונטענת.
